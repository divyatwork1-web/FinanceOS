# FinanceOS

FinanceOS is a financial intelligence platform built using Python, Streamlit, and Pandas. It allows users to upload financial datasets, automatically detect financial structures, track budgets, analyze spending behavior, monitor financial health, and generate actionable insights through interactive dashboards and reports.

## Features

* Financial Data Upload & Analysis
* Automatic Dataset Detection
* Transaction Tracking
* Budget Management
* Financial Health Score
* Spending & Savings Analysis
* Behavioral Insights
* Interactive Dashboards
* Visual Reports
* Tracker + Analyzer Modes

## Tech Stack

* Python
* Streamlit
* Pandas
* NumPy
* Plotly
* OpenPyXL

## How to Run

1. Install dependencies

```bash
pip install -r requirements.txt
```

2. Launch the application

```bash
streamlit run app.py
```
